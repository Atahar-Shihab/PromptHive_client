# PromptHive Client

Next.js JavaScript frontend for the AI Prompt Sharing & Marketplace Platform.

## Key Packages

Next.js, React, Better Auth, Framer Motion, Recharts, Stripe Elements, React Toastify, React Markdown, pdf-lib, Lucide React.

## Run

```bash
npm install
copy ".env.example" ".env"
npm run dev
```

Set `NEXT_PUBLIC_API_URL` to your Express API URL and `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` to your Stripe key.
